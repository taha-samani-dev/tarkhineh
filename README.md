## معرفی

پروژهٔ **ترخینه** یک وب‌اپلیکیشن تک‌صفحه‌ای (SPA) است که با **Next.js** (App Router) و **React** ساخته شده و برای نمایش منو، انتخاب شعبه، سبد خرید، احراز هویت و پرداخت آنلاین استفاده می‌شود. رابط کاربری به‌صورت **RTL** و **فارسی** طراحی شده است.

## نصب و اجرا

### نصب وابستگی‌ها

```bash
npm install
```

### اجرای محیط توسعه (Development)

```bash
npm run dev
```

سرور با **Turbopack** روی آدرس پیش‌فرض (معمولاً `http://localhost:3000`) بالا می‌آید.

### ساخت نسخهٔ پروداکشن (Build)

```bash
npm run build
```

### اجرای نسخهٔ پروداکشن

```bash
npm run start
```

### بررسی کیفیت کد (Lint)

```bash
npm run lint
```

### توضیح کوتاه بخش‌ها

- **app**: فقط روت‌ها و صفحات؛ هر `page.js` یا `layout.js` مطابق قرارداد Next.js است.
- **components**: بر اساس دامین (home, branches, cart, profile, …) و یک لایهٔ مشترک **ui** (دکمه، آیکن، input، تصویر).
- **hooks**: منطق قابل استفادهٔ مجدد (مسیر، لاگین، فرم آدرس، اسلایدر، تایمر و …).
- **store**: وضعیت سراسری (احراز هویت، باز/بسته شدن مودال‌ها، سایدبار پروفایل).
- **lib**: توابع خالص و سرویس‌ها (URL تصویر، تاریخ جلالی، نرمال‌سازی اعداد).
- **constans**: داده‌های استاتیک (اسلایدها، دسته‌ها، لیست شعبه‌ها، متن‌ها).

## قوانین کدنویسی

### پسوند فایل‌ها (`.js` و `.jsx`)

در این پروژه به‌صورت یکدست رعایت می‌شود:

| نوع فایل | پسوند | توضیح |
|----------|--------|--------|
| فایل‌هایی که **`"use client"`** دارند | **`.jsx`** | کامپوننت‌ها و هوک‌های سمت کلاینت |
| فایل‌های **سروری** یا بدون `"use client"` | **`.js`** | صفحات `app`، لایه‌ها، توابع کمکی، داده‌های ثابت |

- **صفحات و لایه‌ها در `app/`** (مثل `page.js`, `layout.js`) همیشه **`.js`** هستند.
- **کامپوننت‌ها و هوک‌هایی که state یا event دارند** و در بالای فایل `"use client"` دارند → **`.jsx`**.
- **آیکن‌ها، کامپوننت‌های presentational بدون state، و فایل‌های داده/کمکی** که `"use client"` ندارند → **`.js`**.

این قانون باعث می‌شود از روی نام فایل بتوان تشخیص داد فایل کلاینت است یا سرور/خنثی.

### مسیرهای import

از alias **`@/`** استفاده می‌شود که به ریشهٔ پروژه اشاره دارد (تنظیم در `jsconfig.json`):

```js
import Header from "@/components/layout/Header/Header";
import { useModal } from "@/store/Modal.store";
import { getImageUrl } from "@/lib/image/getImageUrl";
```

### RTL و زبان

- در `app/layout.js` مقدارهای `lang="fa"` و `dir="rtl"` تنظیم شده‌اند.
- در استایل‌ها و کامپوننت‌ها باید جهت راست‌به‌چپ در نظر گرفته شود.

## مسیرها و صفحات

| مسیر | توضیح |
|------|--------|
| `/` | صفحهٔ اصلی (اسلایدر، جستجو، دسته‌ها، دربارهٔ ما، شعبه‌ها) |
| `/about-us` | دربارهٔ ما |
| `/contact-us` | تماس با ما |
| `/franchise` | اعطای نمایندگی |
| `/search` | جستجو |
| `/help` | راهنما و سوالات متداول |
| `/branches/[branch]` | صفحهٔ شعبه (مثلاً `/branches/ekbatan`) |
| `/branches/[branch]/[menu]` | منوی غذاهای آن شعبه |
| `/branches/[branch]/cart` | سبد خرید همان شعبه |
| `/profile/*` | پروفایل، اطلاعات، آدرس، علاقه‌مندی‌ها، پیگیری سفارش، خروج |
| `/payment/successfull` | پرداخت موفق |
| `/payment/unsuccessfull` | پرداخت ناموفق |

## متغیرهای محیطی

در ریشهٔ پروژه فایل **`.env.local`** (یا `.env`) ایجاد کنید. نمونه:

```env
# آدرس پایهٔ تصاویر (مثلاً Cloudinary)
NEXT_PUBLIC_CLOUDINARY_BASE_URL=https://res.cloudinary.com/...
```

در `next.config.mjs` برای دامنهٔ تصاویر (مثلاً `res.cloudinary.com`) تنظیم **remotePatterns** انجام شده است.

## یادداشت‌ها

- نام پوشهٔ ثابت‌ها در پروژه **`constans`** است (نه `constants`). در importها از همین نام استفاده شود تا با refactor بعدی هماهنگ باشد.
- برای تصاویر از کامپوننت **AppImage** و تابع **getImageUrl** در `lib/image` استفاده شود تا سایز و کیفیت و دامنهٔ مجاز تصاویر یکپارچه باشد.

اگر سوال یا پیشنهادی دارید، در قالب Issue یا در تیم مطرح کنید.
